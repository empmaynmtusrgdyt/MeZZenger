# Meссenger

Клиент-серверный мессенджер на Qt6/C++17 с графическим интерфейсом, тёмной темой и поддержкой личных сообщений.

## Возможности

- Аутентификация (логин/регистрация)
- Личные сообщения между пользователями
- История сообщений
- Поиск контактов
- Тёмная тема (QSS стили)

## Требования

- CMake 3.16+
- Qt 6.2+
- C++17
- Компилятор: GCC 9+, Clang 10+, MSVC 2019+

## Сборка

```bash
mkdir build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
cmake --build . -j$(nproc)
```

## Запуск

Сервер:
```bash
./build/messenger_server [--port 5555]
```

Клиент:
```bash
./build/messenger_client
```
