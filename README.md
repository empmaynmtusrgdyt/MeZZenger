# MeZZenger

Клиент-серверный мессенджер на Qt6/C++17 с графическим интерфейсом, тёмной темой и поддержкой личных сообщений.

## Возможности

- Аутентификация (логин/регистрация)
- Личные сообщения между пользователями
- История сообщений
- Список всех пользователей с отметкой «в сети», поиск по списку
- Уведомления о новых сообщениях (счётчик в заголовке окна, системное уведомление)
- Отправка файлов до 50 МБ (кнопка 📎, скачивание по ссылке в чате)
- Групповые чаты (меню «Группа»: создание, участники, переименование, выход)
- Смена пароля (меню «Аккаунт»)
- Тёмная тема (QSS стили)

## Требования

- CMake 3.16+
- Qt 6.2+
- C++17
- Компилятор: GCC 9+, Clang 10+, MSVC 2019+

## Сборка

```bash
mkdir build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
cmake --build . -j$(nproc)
```

## Запуск

Соединение клиента с сервером шифруется (TLS 1.2+), обычный TCP не принимается.

### 1. Сертификат сервера (один раз)

В каталоге, из которого запускается сервер:
```bash
/путь/к/репозиторию/scripts/gen-cert.sh [имя_хоста_или_IP ...]
```
Скрипт создаёт `server.crt` и `server.key` и печатает отпечаток SHA-256. Ключ `server.key` никому не передавайте и не коммитьте. Сервер при запуске тоже печатает отпечаток.

### 2. Сервер

```bash
./build/mezzenger_server [--port 5555] [--cert server.crt] [--key server.key]
```

### 3. Приглашения

Зарегистрироваться можно только по одноразовому коду. Создайте его на сервере, в том же каталоге, где лежит `server.db` (сервер при этом может работать):
```bash
./build/mezzenger_server --new-invite
```
Команда печатает код вида `ABCD-EFGH-JKMN-PQRS`. Передайте его новому пользователю: он вводит код в поле «Код приглашения» при регистрации. Код сгорает после первой успешной регистрации. В базе хранится только хеш кода. Первого пользователя тоже нужно регистрировать по коду.

### 4. Клиент

```bash
./build/mezzenger_client
```

При первом подключении к серверу клиент покажет отпечаток его сертификата. Сверьте его с отпечатком от администратора сервера и подтвердите: дальше он проверяется автоматически. Если отпечаток изменится, клиент предупредит об этом и предложит решить, доверять ли новому (по умолчанию «Нет»).

## Тесты

```bash
cd build
cmake .. && cmake --build . -j
ctest --output-on-failure
```

Нужны Qt Test и Python 3 (только стандартная библиотека). Тесты поднимают настоящий сервер во временной папке и управляют настоящим клиентом без показа окон; весь прогон занимает около двух минут. `MEZZENGER_SKIP_SLOW=1` пропускает самый долгий тест (таймаут входа, ~31 с). Отключить тесты: `-DMEZZENGER_BUILD_TESTS=OFF`.
